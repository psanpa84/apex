Conexión fácil

Primero despliega o ejecuta el backend de la carpeta backend. Después pega aquí su URL y conecta cada servicio.

P

Polar Flow

Sueño, Nightly Recharge, pulso, zonas, actividad diaria y sesiones grabadas.
S

Strava

Actividades, segmentos, desnivel, potencia, ritmos, frecuencia cardiaca y percepción.
G

Google Sheets

Plan semanal, objetivos, notas del entrenador y sesiones pendientes.
J

Jefit

Fuerza, ejercicios, series, repeticiones, pesos, volumen y progresión. Preparado para CSV/export hasta tener API oficial.
M

MyFitnessPal

Calorías, proteína, grasas, carbohidratos y balance energético. Preparado para CSV/export y posible lectura vía Health Connect.

Arquitectura preparada

La app ya separa las fuentes: Polar para recuperación y biometría, Strava para ejecución, Sheets para planificación, Jefit para fuerza y MyFitnessPal para nutrición. El backend incluido guarda secretos fuera de GitHub Pages y expone una sincronización simple para el panel.
